# AGENTS.md

My shared instructions for **Codex, Claude Code, OpenCode, Cursor, and GitHub Copilot**.

[Read the rules → AGENTS.md](AGENTS.md)

I keep one master file and symlink each agent’s instruction file to it, so edits stay consistent across my local setup. Git keeps the version history and remote copy.

The rules cover development workflows, backups, handling secrets and untrusted content, marketing, mobile testing, OpenSSF practices and GitHub community standards, and store automation.

If you adapt this setup, customize the paths, email address, app IDs, tools, and personal workflows first. Back up your existing instructions before linking them, and check that your agent loads its instruction file.

These instructions guide agent behavior; they do not enforce security permissions or replace tool-level access controls.
